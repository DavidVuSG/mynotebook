## Part 1. Tenses (12)

### 1.1 Master table: formula + signal words

| # | Tense | Formula (+) | Signal words |
|---|-------|-------------|--------------|
| 1 | Present Simple | S + V(s/es) · be: am/is/are | every day/week, always, usually, often, sometimes, seldom, rarely |
| 2 | Present Continuous | S + am/is/are + V-ing | now, right now, at the moment, at present, Look!, Listen!, Be quiet!, Watch out! |
| 3 | Present Perfect | S + have/has + V3/ed | just, recently, lately, already, before, not…yet, ever, never, since, for, so far = until now = up to now, superlative |
| 4 | Present Perfect Continuous | S + have/has + been + V-ing | all day/week/month, since, for |
| 5 | Past Simple | S + V2/ed · be: was/were | ago, yesterday, last night/month…, in + past year |
| 6 | Past Continuous | S + was/were + V-ing | at 5pm last Sunday, at this time last night, when/while/as, from 4pm to 9pm |
| 7 | Past Perfect | S + had + V3/ed | by the time, prior to that time, as soon as, when, before, after, until then |
| 8 | Past Perfect Continuous | S + had been + V-ing | before, after, until then, since, for |
| 9 | Future Simple | S + will/shall + V | tomorrow, in + time, next week/month/year, 10 years from now |
| 10 | Future Continuous | S + will/shall + be + V-ing | next year, next week, next time, in the future, at this time next Saturday |
| 11 | Future Perfect | S + will/shall + have + V3/ed | by/before + future time, by the time, by the end of + future time |
| 12 | Future Perfect Continuous | S + will have been + V-ing | for + duration + by/before + future time, by then, by the time |

**Negative / Question (all tenses):**
- Negative: put `not` after the first auxiliary (`don't/doesn't`, `isn't`, `haven't`, `didn't`, `wasn't`, `hadn't`, `won't`…).
- Question: move the first auxiliary before S.
- Present/Past Simple with normal verbs: `do/does/did + S + V_inf?`; the main verb goes back to base form.

### 1.2 Usage by tense

#### Present
| Tense                          | Use                                              | Example                                             |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------- |
| **Present Simple**             | Facts / truths                                   | The sun rises in the East.                          |
|                                | Habits                                           | He gets up early every morning.                     |
|                                | Abilities                                        | He plays badminton very well.                       |
|                                | Fixed schedule (future)                          | The train leaves at 9 am tomorrow.                  |
| **Present Continuous**         | Happening now                                    | The children are playing football now.              |
|                                | After commands                                   | Look! The child is crying.                          |
|                                | Annoying repetition (with *always*)              | She is always borrowing our books.                  |
|                                | Near-future plan                                 | Tomorrow, I am taking the train to Ohio.            |
| **Present Perfect**            | Unspecified time in the past                     | I have done my homework.                            |
|                                | Repeated past action                             | I have seen that film three times.                  |
|                                | With *since* / *for*                             | She has lived in Liverpool all her life.            |
| **Present Perfect Continuous** | Stress duration (started in past, continues now) | She has been learning English for 6 years.          |
|                                | Just finished, result visible now                | I am exhausted because I have been working all day. |

> **Since vs For**
> - **since** + point in time (since 1995, since this morning)
> - **for** + length of time (for 6 years, for two weeks)

> ⚠️ **No continuous form for stative verbs:** be, understand, know, like, want, see, hear, glance, feel, think, smell, love, hate, realize, seem, remember, forget. Use **Present Simple** instead.

#### Past
| Tense | Use | Example |
|-------|-----|---------|
| **Past Simple** | Finished action | I went to the cinema 3 days ago. |
| | Past habit (*used to*) | I used to go swimming when I was young. |
| | Sequence of actions | I got up, brushed my teeth, and then had breakfast. |
| | Conditional type 2 (if-clause) | If you studied hard, you could pass the exam. |
| **Past Continuous** | Action in progress at a past moment | I was having dinner at 7 last night. |
| | Interrupted action (*when*: Past Simple interrupts) | I was watching TV when she called. |
| | Parallel actions (*while*) | While Ellen was reading, Tom was watching TV. |
| **Past Perfect** | Done before a past moment | By 4pm yesterday, he had left. |
| | Earlier of two past actions | Before she went to bed, she had done her homework. |
| | Conditional type 3 (if-clause) | If you had studied hard, you could have passed. |
| **Past Perfect Continuous** | Duration of an action before another past action | Sam gained weight because he had been overeating. |

> ⚠️ Source translation fix: "If you studied hard, you could pass" means "you **would be able to** pass" (hypothetical present), not "you passed".

#### Future
| Tense | Use | Example |
|-------|-----|---------|
| **Future Simple** | Prediction without evidence | I think it will rain. |
| | Spontaneous decision | I will bring coffee to you. |
| | Offer / promise / threat | I will never speak to you again. |
| | Main clause of conditional type 1 | If you don't hurry, you will be late. |
| **Future Continuous** | In progress at a future moment | She will be climbing the mountain at this time next Saturday. |
| | Part of a schedule | The party will be starting at nine o'clock. |
| **Future Perfect** | Finished before a future moment | I will have finished my homework by 9 o'clock. |
| **Future Perfect Continuous** | Duration up to a future moment | We will have been living here for 10 years by next month. |

### 1.3 Memory tricks

- **Perfect = have + V3** (any time: have/has, had, will have).
- **Continuous = be + V-ing** (any time: am/is/are, was/were, will be).
- **Perfect Continuous = have + been + V-ing** (stresses *how long*).
- **Simple** = single fact/habit/finished event.
- **when + Past Simple** interrupts; **while + Past Continuous** is the long action.
- **for/since** → Perfect or Perfect Continuous.
- **by the time / by + time** → Perfect (Past or Future).

## Part 2. Quantifiers (Bổ ngữ chỉ lượng)

| Noun type | Use |
|-----------|-----|
| **Plural countable** | many, (a) few, a number of, the number of, a lot of |
| **Singular countable** | each, every, another |
| **Uncountable** | much, (a) little, a great deal of, the amount of, less, the least, a lot of |

> **Few / a few** (countable): *few* = almost none (negative), *a few* = some (positive).
> **Little / a little** (uncountable): same contrast.
> ⚠️ **a number of + plural noun → plural verb**; **the number of + plural noun → singular verb**.
> ⚠️ **fewer** + countable, **less** + uncountable.

## Part 3. Linking Words (Liên từ)

### 3.1 Reason (vì / bởi vì)

| Word | Followed by | Example |
|------|-------------|---------|
| because, since, as, seeing that | **Clause (S+V)** | He stole because he wanted the money. |
| because of, due to, owing to, as a result of, thanks to | **Noun / N-phrase** | Many deaths in 2020 were due to Covid-19. |

> ⚠️ **as a result of** = *because of* (+ noun). **as a result** (alone, with comma) = *therefore* (shows result).

### 3.2 Result (nên / do đó)

| Word | Pattern |
|------|---------|
| **so** | Clause, **so** clause |
| **therefore, consequently, as a result** | Clause. **Therefore,** clause |
| **so … that** | so + adj/adv + that + clause |
| **such … that** | such + (a/an) + (adj) + noun + that + clause |

> It rained, **so** I brought an umbrella.
> Julia ate **so fast that** everyone was surprised.

### 3.3 Purpose (để)

| Word | Followed by |
|------|-------------|
| in order to, so as to | **V (base)** |
| so that, in order that | **Clause** |

### 3.4 Contrast (đối lập)

| Word | Followed by |
|------|-------------|
| but, while, whereas | Clause (while/whereas can also join noun contrasts) |
| however | Clause (new sentence, comma after) |
| although, even though, even if | **Clause** |
| despite, in spite of | **Noun / N-phrase / V-ing** |

> ⚠️ Correct: **despite** heavy rain / **in spite of** heavy rain. **"despite of" is wrong.**

### 3.5 Time

| Word | Followed by |
|------|-------------|
| whenever, every time | Clause |
| when, while, as, after | Clause |
| during, throughout, all through | **Noun phrase** |
| first, then, later | Clause (sequencing) |

### 3.6 Condition

| Word | Meaning |
|------|---------|
| even if, as long as, unless | Even if / provided that / if not |
| whether … or not | regardless of |
| in case | as a precaution |

### 3.7 Addition

| Word | Followed by |
|------|-------------|
| as well as | Noun / Adj / Phrase / V-ing |
| besides, in addition (to that), furthermore | Clause |
| too, as well, not … either | End of sentence |

## Part 4. Other Structures

### 4.1 Another / Other / The other

| Form | Used with | Meaning |
|------|-----------|---------|
| **another** | singular countable | one more / a different one |
| **other** | plural countable (⚠️ for uncountable, use *some more / other kinds of*) | some more / different ones |
| **the other** | singular countable | the last remaining one |
| **the other** | plural countable | all the remaining ones |
| **others** | (pronoun) | some others (no noun after) |
| **the others** | (pronoun) | all the rest |

> If the noun was already mentioned, drop it: *I don't want this book. Please give me the other.*
> ❌ **others + noun**.

### 4.2 Prepositions

| Type | Rule |
|------|------|
| **Time** | **at** (hours) · **on** (days/dates) · **in** (months, years, seasons, centuries) · before · after · **during** + time noun |
| **Place** | **at** (small spot: school, airport) · **in** (large area/inside: city, country) · **on** (surface contact) · above / over (higher) |
| **Movement** | **to** (toward) · **into** (to the inside) · **onto** (to a surface) · from (origin) · across · along · around |
| **Manner** | with · without · according to + N · in spite of · instead of |
| **Purpose** | to · in order to · so as to · for |
| **Reason** | thanks to (good cause) · through · because of · owing to · by means of |

### 4.3 A / An / The

| Article | Use |
|---------|-----|
| **an** | **vowel sound**: an aircraft, an hour (silent h), an uncle, an S.O.S |
| **a** | **consonant sound**: a university, a uniform (sounds like "yu"), a lot of, a dozen, a hundred, a half, $5 a kilo, 60 km an hour |
| **the** | specific / already mentioned / unique / known to both speaker and listener |

> **the earth**, **the boy in the corner**; but **Sugar is sweet** (general) vs **The sugar on the table** (specific).
> ⚠️ Rule is based on **sound**, not spelling.

### 4.4 Pronouns & possessives

| Subject | Object | Possessive adj. | Possessive pron. | Reflexive |
|---------|--------|-----------------|------------------|-----------|
| I | me | my | mine | myself |
| you | you | your | yours | yourself / yourselves |
| we | us | our | ours | ourselves |
| they | them | their | theirs | themselves |
| he | him | his | his | himself |
| she | her | her | hers | herself |
| it | it | its | (its) | itself |

### 4.5 Modal verbs

| | Form |
|--|------|
| (+) | S + modal + V |
| (−) | S + modal + not + V |
| (?) | Modal + S + V? |

### 4.6 Verbs followed by TO-V or V-ing

#### Meaning changes (⭐ high test frequency)

| Verb | + **to V** | + **V-ing** |
|------|-----------|-------------|
| **like** | choice / habit: *I like to drink milk.* | enjoyment: *I like watching TV.* |
| **remember** | remember to do (future duty): *She remembers to wash dishes.* | remember having done (past): *She remembers washing dishes yesterday.* |
| **regret** | regret to say/tell (bad news now): *I regret to tell you…* | regret having done (past): *I regret playing too much.* |
| **stop** | stop *in order to* do: *I stop to rest.* | stop the activity: *I stop talking about Linh.* |
| **try** | make an effort: *She tries her best to pass.* | experiment: *I try doing a new job.* |
| **go on** | continue to a *new* action | continue the *same* action |
| **mean** | intend: *I mean to leave.* | involve / result in: *This means waiting.* |

> Also: **forget** works like remember (forget to do = didn't do it; forget doing = forget a past action).

#### No meaning change (both OK)
begin · start · continue · intend · bother · propose · allow · permit · recommend · suggest · advise · remind

### 4.7 Comparisons

| Type | Short adj/adv | Long adj/adv (3+ syllables) |
|------|---------------|-----------------------------|
| **Comparative** | adj-**er** + than | **more/less** + adj + than |
| **Superlative** | **the** adj-**est** + in/of | **the most/least** + adj + in/of |

**Examples:** colder, quieter · more beautiful, more important
**Superlative:** John is **the tallest** boy **in** the family. She is **the shortest of** three sisters.

> ⚠️ Adjectives ending **-ed, -ing, -ish, -ous** always take *more*: more boring, more useful.
> ⚠️ **Never** double: ❌ *more faster* → ✅ *faster*.
> Irregular: good → better → best · bad → worse → worst · far → farther/further → farthest/furthest · many/much → more → most · little → less → least.

**With nouns:**
- More: S + V + **more** + N + than…
- Less: S + V + **fewer** (countable) / **less** (uncountable) + N + than…

**One of the + superlative + plural noun + singular verb:**
> *One of the best students **is** here.*

## Part 5. Conditionals

| Type | If-clause | Main clause | Use |
|------|-----------|-------------|-----|
| **0** | If + Present Simple | Present Simple | Facts, instructions |
| **1** | If + Present Simple | will + V | Real / possible future |
| **2** | If + Past Simple | would/should + V | Unreal present/future |
| **3** | If + Past Perfect (had V3) | would have + V3 | Unreal past (regret) |
| **Mixed** | If + Past Perfect | would + V | Past condition → present result |

**Examples**
- **0:** If you freeze water, it becomes solid.
- **1:** If you don't hurry, you will be late.
- **2:** If you studied hard, you would pass the exam.
- **3:** If you had studied hard, you would have passed the exam.
- **Mixed:** If I had studied medicine, I would be a doctor now.

> **Mnemonic:** *0 = truth · 1 = real · 2 = imaginary now · 3 = imaginary past · Mixed = past cause, present result.*
> ⚠️ In type 2, *were* is used for all subjects in formal English: *If I were you…*

## Part 6. Relative Clauses

| Pronoun | Replaces | Role | Example |
|---------|----------|------|---------|
| **who** | person | subject | the boy **who** is my son's friend |
| **whom** | person | object | the girl **whom** I spoke to |
| **which** | thing | subject / object | a company **which** makes cars |
| **that** | person / thing | subject / object | the boy **that** is my friend's son |
| **whose** | possession (his/her/its/their) | + noun | the cat **whose** leg was broken |
| **where** | place (there / at that place) | | the place **where** we go once a week |
| **when** | time (then / on that day) | | the day **when** we first met |
| **why** | reason (for that reason) | | the reason **why** you are sad |

> ⚠️ **"that" cannot be used** after a comma (non-defining clause) or right after a preposition (use *whom/which*).

## Part 7. Not only … but also

**Pattern:** `not only` + **X** + `but also` + **X** (same word type or structure on both sides)

| ✅ Correct (parallel) | ❌ Wrong |
|----------------------|----------|
| He is famous **not only in Italy but also in Switzerland**. | He is **not only famous** in Italy but also **in Switzerland** (unbalanced) |
| She is **not only** smart **but also** kind. | She is not only smart but also **is** kind |

> Rule: whatever comes after *not only* must be the same grammar type as what comes after *but also* (adj–adj, noun–noun, V–V, phrase–phrase).

## Part 8. Passive Voice

**Formula:** S + **be (in the tense of the active verb)** + **V3/ed** (+ by agent)
**Steps:** (1) object → subject · (2) be in same tense · (3) main verb → V3 · (4) subject → *by + agent* (often dropped).

| Tense | Active | Passive |
|-------|--------|---------|
| Present Simple | She writes a letter. | A letter **is written**. |
| Present Continuous | She is writing a letter. | A letter **is being written**. |
| Present Perfect | She has written a letter. | A letter **has been written**. |
| Past Simple | She wrote a letter. | A letter **was written**. |
| Past Continuous | She was writing a letter. | A letter **was being written**. |
| Past Perfect | She had written a letter. | A letter **had been written**. |
| Future Simple | She will write a letter. | A letter **will be written**. |
| Future Perfect | She will have written a letter. | A letter **will have been written**. |
| Modal | She must write a letter. | A letter **must be written**. |
| Infinitive | She wants to write a letter. | A letter **wants to be written** → *She wants the letter to be written.* |
| Gerund | She enjoys writing letters. | She enjoys **being written to**. |

**Special cases**
- **Two objects:** *He gave me a book* → *I was given a book* / *A book was given to me.*
- **Reporting verbs:** *People say that he is rich* → **It is said that he is rich** / **He is said to be rich.**
- **Get-passive (informal):** *He got fired.*
- **Impersonal:** It is believed / thought / said / reported / expected that…
- **Need + V-ing = need to be V3:** *The car needs washing = The car needs to be washed.*
- Intransitive verbs (happen, arrive, die, seem, occur) have **no passive**.
- Perfect Continuous & Future Continuous passives are rare: avoid.

## Part 9. Reported Speech (Indirect Speech)

### 9.1 Backshift (tense changes)

| Direct | Reported (reporting verb in past) |
|--------|-----------------------------------|
| Present Simple | Past Simple |
| Present Continuous | Past Continuous |
| Present Perfect | Past Perfect |
| Past Simple | Past Perfect |
| Past Continuous | Past Perfect Continuous |
| will | would |
| can | could |
| may | might |
| must | had to |
| shall | should/would |
| Past Perfect, would, could, should, might, ought to | **no change** |

> **No backshift** if the statement is a general truth or still true: *He said the Earth **is** round.* / reporting verb is present (*He says…*).

### 9.2 Pronoun / time / place changes

| Direct | Reported |
|--------|----------|
| now | then / at that time |
| today | that day |
| tonight | that night |
| yesterday | the day before / the previous day |
| tomorrow | the next day / the following day |
| last week | the week before / the previous week |
| next week | the week after / the following week |
| ago | before |
| this / these | that / those |
| here | there |
| I / my / me | (depends on speaker: he / his / him) |

### 9.3 Sentence types

| Type | Pattern | Example |
|------|---------|---------|
| **Statement** | S + said (that) + clause | "I am tired." → He said (that) he **was** tired. |
| **Yes/No question** | asked + if/whether + S + V (**no inversion, no ?**) | "Do you like tea?" → She asked **if** I **liked** tea. |
| **Wh-question** | asked + wh-word + S + V | "Where do you live?" → He asked **where I lived**. |
| **Command** | told/ordered + O + **to V** | "Sit down!" → He told me **to sit down**. |
| **Negative command** | told + O + **not to V** | "Don't go!" → She told me **not to go**. |
| **Request** | asked + O + to V | "Please help me." → She asked me **to help** her. |

### 9.4 Reporting verbs (very common in tests)

| Pattern | Verbs |
|---------|-------|
| **V + that + clause** | say, tell (+O), claim, state, announce, explain, admit, deny, complain, mention, promise, warn |
| **V + O + to V** | tell, ask, advise, warn, order, remind, invite, encourage, persuade, urge, beg, allow |
| **V + to V** | promise, offer, agree, refuse, threaten, demand |
| **V + V-ing** | admit, deny, suggest, recommend, apologise for (+V-ing), insist on |
| **V + O + prep + V-ing** | accuse sb **of**, blame sb **for**, congratulate sb **on**, thank sb **for**, warn sb **against**, criticise sb **for**, prevent sb **from** |

> ⚠️ **say** has no object: *say that…* / *say to him*. **tell** needs an object: *tell him that…*
> ⚠️ **suggest** is never followed by *O + to V*: ✅ *He suggested going / that we go.*

## Part 10. Subject–Verb Agreement

| Rule | Example |
|------|---------|
| **Either…or / Neither…nor / Not only…but also / or / nor** → verb agrees with the **nearer** subject | Neither the teacher nor the **students are** here. |
| **Both…and / and** → plural verb | Tom and Jerry **are** friends. |
| **with / together with / as well as / along with / in addition to** → verb agrees with the **first** subject | The teacher, together with her students, **is** coming. |
| **Everyone, everybody, someone, anyone, nobody, each, every + N, either, neither** → **singular** | Everyone **has** a book. |
| **the + adj** (the rich, the poor, the young) → **plural** | The poor **need** help. |
| **Distance / money / time / weight as a unit** → **singular** | Ten dollars **is** enough. |
| **News, mathematics, physics, economics, politics, measles, diabetes** → **singular** | Mathematics **is** difficult. |
| **Scissors, trousers, glasses, jeans, clothes, police, people, cattle** → **plural** | The police **are** coming. |
| **A number of + plural N** → plural verb · **The number of + plural N** → singular verb | A number of students **are** absent. / The number of students **is** growing. |
| **One of the + plural N** → singular verb | One of my friends **is** a doctor. |
| **Gerund / infinitive as subject** → singular | Swimming **is** fun. |
| **Collective nouns** (family, team, government) → singular (unit) or plural (members) | The team **is/are** winning. |
| **There is/are** → agrees with the **noun after** it | There **are** two books on the desk. |
| **Relative clause** → verb agrees with the **antecedent** | The man who **lives** next door… |
| **Titles / names of books, countries, companies** → singular | The United States **has**… |

## Part 11. Gerund (V-ing) vs Infinitive (to V): Extended

### 11.1 Verbs + V-ing

> **Mnemonic:** *"MEGAFAPS DIQ"*: **M**ind · **E**njoy · **G**o (go swimming) · **A**void · **F**inish · **A**dmit · **P**ractise · **S**uggest · **D**eny · **I**magine · **Q**uit

Also: consider, keep (on), risk, postpone, delay, miss, dislike, can't help, can't stand, resent, escape, involve, fancy, appreciate, recall, mention, recommend, look forward to, give up, put off, carry on.

### 11.2 Verbs + to V

> **Mnemonic:** *"WANT PLAN HOPE DECIDE"*

want, would like, need, hope, expect, plan, decide, promise, offer, refuse, agree, learn, manage, fail, afford, arrange, pretend, seem, appear, tend, threaten, wish, choose, intend, deserve, prepare, claim.

### 11.3 Verbs + O + to V
tell, ask, advise, allow, permit, want, order, invite, encourage, persuade, force, remind, warn, expect, teach, enable, get (*get sb to do*), cause, require.

### 11.4 Bare infinitive (V without to)
- After **modals** (can, must, should, may, will…)
- **make / let / have + O + V** (*She made me cry. He let me go. I had him fix it.*)
- **help + O + (to) V**
- **see / hear / watch / notice + O + V** (whole action) or **V-ing** (in progress)
- **had better / would rather / would sooner + V**
- **why not + V**

> ⚠️ **Passive of make:** *I was made **to** cry.* (to returns in passive)

### 11.5 Other patterns

| Pattern | Rule | Example |
|---------|------|---------|
| **Preposition + V-ing** | Always V-ing | interested in learning, good at swimming |
| **look forward to / be used to / object to / in addition to / committed to / get round to + V-ing** | *to* here is a **preposition** | I look forward to meeting you. |
| **Adj + to V** | easy, difficult, happy, ready, glad, sorry, afraid, eager, able, likely | It is easy **to learn**. |
| **too + adj + to V** | too … to (cannot) | He is too tired **to walk**. |
| **adj + enough + to V** / **enough + N + to V** | enough … to (can) | She is old enough **to drive**. |
| **It takes (time) to V** | | It takes an hour **to get** there. |
| **It's no use / no good / worth / a waste of time + V-ing** | | It's no use **crying**. |
| **There's no point in + V-ing** | | There's no point in **waiting**. |
| **spend / waste time + V-ing** | | I spent two hours **studying**. |
| **have difficulty / trouble / fun + V-ing** | | She has difficulty **sleeping**. |
| **busy / worth + V-ing** | | The book is worth **reading**. |
| **Purpose** | to V / in order to V / so as to V | |

## Part 12. Used to / Be used to / Get used to

| Structure | Meaning | Followed by | Example |
|-----------|---------|-------------|---------|
| **used to** + V | past habit / state (no longer true) | base verb | I **used to smoke**. |
| **be used to** + V-ing/N | accustomed to | V-ing / noun | I **am used to getting up** early. |
| **get used to** + V-ing/N | become accustomed | V-ing / noun | She **got used to living** alone. |
| **would** + V | repeated past action (not states) | base verb | Every summer we **would visit** Grandma. |

> Negative/question of *used to*: **didn't use to** / **Did you use to…?** (no *d*).

## Part 13. Wish / If only / Would rather / It's time

| Situation | Structure | Example |
|-----------|-----------|---------|
| **Wish about present / future** (unreal now) | wish + **Past Simple** (*be → were*) | I wish I **were** taller. I wish I **had** a car. |
| **Wish about past** (regret) | wish + **Past Perfect** | I wish I **had studied** harder. |
| **Wish for change** (complaint, annoyance) | wish + **would** + V | I wish you **would stop** talking. |
| **If only** (stronger than wish) | same tenses as wish | If only I **had** more time! |
| **would rather** (same subject) | would rather + **V** | I'd rather **stay** home. |
| **would rather** (different subjects, present/future) | S + would rather + S + **Past Simple** | I'd rather you **stayed**. |
| **would rather** (different subjects, past) | S + would rather + S + **Past Perfect** | I'd rather you **hadn't said** that. |
| **It's (high) time** | It's time + S + **Past Simple** | It's time you **went** to bed. |
| **as if / as though** (unreal) | Past Simple (present) / Past Perfect (past) | He talks as if he **knew** everything. |
| **suppose / supposing** | Past Simple (present) / Past Perfect (past) | Suppose you **won** the lottery… |

> ⚠️ After *wish*, **were** is used for **all subjects**: *I wish he **were** here.*

## Part 14. Inversion (Đảo ngữ)

**Pattern:** negative / restrictive adverb at the beginning + **auxiliary + S + V**

| Trigger | Structure | Example |
|---------|-----------|---------|
| **Never / Rarely / Seldom / Little / Hardly ever** | + aux + S + V | Never **have I seen** such a thing. |
| **No sooner … than** | No sooner + **had** S + V3 + **than** + S + V2 | No sooner **had** I arrived **than** it rained. |
| **Hardly / Barely / Scarcely … when** | Hardly + **had** S + V3 + **when** + S + V2 | Hardly **had** he left **when** she called. |
| **Not only … but also** | Not only + **aux** + S + V, but also … | Not only **did she sing**, but she also danced. |
| **Not until** | Not until + clause/time + **aux + S + V** | Not until midnight **did he come** home. |
| **Only when / Only after / Only if / Only by / Only then** | Only + … + aux + S + V | Only then **did I understand**. |
| **At no time / On no account / Under no circumstances / In no way / By no means** | + aux + S + V | Under no circumstances **must you open** it. |
| **So + adj/adv … that** | So + adj + **be** + S + that | So beautiful **was** the view that we stopped. |
| **Such … that** | Such + **be** + N + that | Such **was** his anger that he left. |
| **Neither / Nor / So** | So/Neither + aux + S | "I'm tired." → So **am** I. / Neither **do** I. |
| **Conditional type 1 (should)** | Should + S + V, … | **Should** you need help, call me. |
| **Conditional type 2 (were)** | Were + S + to V / Were + S… | **Were** I you, I would go. |
| **Conditional type 3 (had)** | Had + S + V3, … would have V3 | **Had** I known, I would have come. |
| **Place / direction adverbs** | Here/There/In/On + V + S | Here **comes** the bus. |

> **Mnemonic:** *Negative word first → auxiliary jumps in front of the subject.*

## Part 15. Participle Clauses & Reduction of Relative Clauses

### 15.1 Reducing relative clauses

| Type | Rule | Example |
|------|------|---------|
| **Active** (who/which + V) | → **V-ing** | The man **who is standing** there → The man **standing** there |
| **Passive** (who/which + be V3) | → **V3/ed** | The book **which was written** by him → The book **written** by him |
| **Superlative / first / last / only** | → **to V** | the first person **who arrived** → the first person **to arrive** |

### 15.2 Joining clauses with same subject

| Meaning | Rule | Example |
|---------|------|---------|
| **Simultaneous / reason** (active) | **V-ing** | **Walking** home, I met Tom. |
| **Earlier action** (active) | **Having V3** | **Having finished** work, he went home. |
| **Passive** | **(Being) V3 / Having been V3** | **Built** in 1990, the bridge is old. |
| **Negative** | **Not + V-ing** | **Not knowing** the answer, I stayed silent. |

> ⚠️ **Same-subject rule:** the subject of both clauses must be the same.
> ❌ *Walking down the street, the rain started.* → ✅ *Walking down the street, I felt the rain.*

## Part 16. Causative, Question Tags, Emphasis

### 16.1 Causative (nhờ / thuê ai làm)

| Structure | Meaning | Example |
|-----------|---------|---------|
| **have + O (person) + V** | arrange for someone to do | I **had** the mechanic **fix** my car. |
| **have + O (thing) + V3** | have something done | I **had** my car **repaired**. |
| **get + O (person) + to V** | persuade someone | I **got** him **to help** me. |
| **get + O (thing) + V3** | have something done | She **got** her hair **cut**. |
| **make + O + V** | force | They **made** him **work**. |
| **let + O + V** | allow | She **let** me **go**. |

### 16.2 Question tags

| Statement | Tag | Example |
|-----------|-----|---------|

| No aux (Present/Past Simple) | do/does/did | She works here, **doesn't she?** |

### 16.3 Cleft sentences (emphasis)

| Pattern | Example |
|---------|---------|
| **It is/was + focus + that/who + clause** | **It was John who** broke the window. |
| **What + S + V + is/was + …** | **What I need is** a rest. |
| **All / The only thing + S + V + is …** | **All I want is** peace. |

## Part 17. Nouns, Adjectives & Word Formation

### 17.1 Plural nouns & countability

| Rule | Example |
|------|---------|
| Add **-s** | book → books |
| **-s, -x, -ch, -sh, -z** → **-es** | box → boxes, watch → watches |
| Consonant + **y** → **-ies** | city → cities |
| **-f / -fe** → **-ves** | knife → knives, leaf → leaves |
| Irregular | man → men, child → children, foot → feet, tooth → teeth, mouse → mice, person → people |
| Same form | sheep, fish, deer, series, species |
| **Always uncountable** | advice, information, furniture, luggage, news, equipment, knowledge, progress, research, homework, money, traffic, weather, work |
| Measure uncountables | **a piece of** advice, **a slice of** bread, **a bottle of** water |

### 17.2 Order of adjectives (OSASCOMP)

> **O**pinion → **S**ize → **A**ge → **S**hape → **C**olour → **O**rigin → **M**aterial → **P**urpose → NOUN
> *a beautiful big old round red Italian leather sports bag*

### 17.3 -ed vs -ing adjectives
- **-ed**: how a person **feels** (*I am bored / interested / excited / tired*)
- **-ing**: what **causes** the feeling (*The film is boring / interesting / exciting*)

### 17.4 Word formation (suffixes)

| Make… | Suffixes | Examples |
|-------|----------|----------|
| **Noun** (person) | -er, -or, -ist, -ian, -ant, -ee | teacher, actor, artist, musician, assistant, employee |
| **Noun** (thing/idea) | -tion, -sion, -ment, -ness, -ity, -ance/-ence, -ship, -hood, -dom, -ism, -ure | education, decision, development, happiness, ability, importance |
| **Verb** | -ize/-ise, -ify, -en, -ate, en-/em- (prefix) | modernise, simplify, widen, activate, enlarge |
| **Adjective** | -ful, -less, -ous, -ive, -al, -able/-ible, -ic, -ical, -ish, -y, -ent/-ant | useful, careless, famous, active, national, comfortable, economic |
| **Adverb** | -ly | quickly, carefully |
| **Negative prefixes** | un-, in-, im- (before b/m/p), il- (before l), ir- (before r), dis-, mis-, non- | unhappy, impossible, illegal, irregular, disagree, misunderstand |

> **Position clues**
> - After **the / a / possessive / adj** → **noun**
> - After **subject** → **verb**
> - Before **noun** or after **be / seem / become / look / feel** → **adjective**
> - Modifying **verb / adj / adv / whole sentence** → **adverb**

### 17.5 Confusing adjectives / adverbs

| Adjective | Adverb |
|-----------|--------|
| good | **well** |
| fast / hard / late / early | same form (also *hardly* = barely, *lately* = recently) |
| friendly, lovely, lonely, elderly | no -ly form → use *in a friendly way* |

## Part 18. More Useful Structures

### 18.1 As … as / Comparisons extended

| Pattern | Example |
|---------|---------|
| **as + adj/adv + as** (equal) | She is **as tall as** her sister. |
| **not as/so + adj + as** | He is **not as tall as** her. |
| **twice / three times as … as** | It costs **twice as much as** that. |
| **the same + N + as** | the same age **as** me |
| **different from** | different **from** (not *than*) |
| **The + comparative, the + comparative** | **The more** you practise, **the better** you get. |
| **Double comparative** | It's getting **hotter and hotter**. / **more and more** expensive. |
| **by far / far / much + comparative or superlative** | **by far the best** · **much** better |
| **no sooner … than** | (see Inversion) |

### 18.2 Too / Enough / So / Such

| Pattern | Meaning | Example |
|---------|---------|---------|
| **too + adj + (for sb) + to V** | excessive → cannot | It's **too hot to go** out. |
| **adj + enough + to V** | sufficient → can | He is **tall enough to reach**. |
| **enough + N** | | We have **enough money**. |
| **so + adj/adv + that** | | She was **so tired that** she slept. |
| **such + (a/an) + (adj) + N + that** | | It was **such a good film that**… |
| **so much / so many + N + that** | | **so many people that** … |

### 18.3 Time clauses: tense rules

| Main clause | Time clause (when/while/before/after/as soon as/until/by the time) |
|-------------|----------------------------------------------------------------------|
| **Future** | **Present Simple** or Present Perfect, **not will** |
| **Past** | Past Simple / Past Perfect |

> ✅ *I will call you when I **arrive**.* ❌ *when I will arrive.*
> ✅ *By the time you come, I **will have finished**.*

### 18.4 Similar structures

| Structure | Example |
|-----------|---------|
| **It's the first/second time + Present Perfect** | It's the first time I **have seen** snow. |
| **It's/It was the first time + Past Perfect** | It was the first time I **had seen** snow. |
| **This is the best/worst … + Present Perfect** | This is the best film I **have ever seen**. |
| **Prefer + N/V-ing + to + N/V-ing** | I prefer tea **to** coffee. / I prefer walking **to** driving. |
| **Prefer to V + rather than V** | I prefer **to walk rather than drive**. |
| **It takes + O + time + to V** | It **took me** two hours **to finish**. |
| **There is no need to V / needn't V** | You **needn't come**. |
| **Be + supposed to V** | You are **supposed to wait** here. |
| **Be + about to V / on the point of V-ing** | The train is **about to leave**. |
| **Be + likely / unlikely to V** | She is **likely to win**. |
| **Have/has + O + to V** | I have **a lot of work to do**. |
| **Neither / either / both of + plural N** | **Neither of** them **is** here. |
| **All / Most / Some / Many of + the + plural N** | **Most of** the students **are**… |
| **Although / Though … yet/still** | **Although** he is rich, **he is** unhappy. (no *but*) |
| **Because … so** | ❌ *Because it rained, so I stayed.* → ✅ one of them only. |

## Part 19. Modal Verbs in Detail

| Modal | Uses | Example |
|-------|------|---------|
| **can / could** | ability · permission · possibility | She **can** swim. **Could** I come in? |

### Perfect modals (about the past)

| Structure | Meaning | Example |
|-----------|---------|---------|

## Part 9. Corrections Made to the Source

| Source said | Corrected |
|-------------|-----------|
| "She is not doing **his** homework" | **her** homework |
| "despite **of** heavy rain" | **despite** / **in spite of** |
| *as a result of* and *as a result* grouped together | *as a result of* + noun (reason); *as a result,* + clause (result) |
| Conditional 2 translated as past ("đã đậu") | Hypothetical: "would pass" |
| "Other + uncountable noun" | Use *some more / other kinds of* |
| "I come from vietnamese" | I come from **Vietnam** (noun, not adjective) |
| Not only … but also example not parallel | Both sides must match |
| "amount of" | **the amount of** |
| Present Perfect "so sánh nhất" signal | Superlative: *It's the best film I have ever seen.* |
